WHY THIS HAPPENED
New called the demo setup and added the editorial photo and textured paper.
The fix gives new artwork pure-white paper and one empty paint layer.
It also prevents a late demo-photo load from resetting the new drawing's undo
history. The first-opening demo remains available.

APPLY TO YOUR LIVE APP
1. Extract this ZIP.
2. Open https://github.com/HAYMOHSEN/Rasmora-Studio
3. Use Add file > Upload files at the repository root.
4. Upload index.html and sw.js from this ZIP, replacing those two existing files.
5. Commit the changes to the main branch. This updates your published app after
   the GitHub Pages deployment completes.
6. Close all Rasmora Studio tabs and any installed app window. Reopen the site,
   let its offline update finish, then close and reopen once more if you still
   see the old New confirmation. Save any current artwork before reloading.
7. Click New and accept the confirmation. It should show pure-white paper
   with an empty Layer 1, without the demo photograph.
